# Bike Sharing Demand Prediction Dashboard

## Project Overview

This project predicts bike-sharing demand using machine learning.

## Machine Learning Models

The project compares four models:

1. Linear Regression
2. Decision Tree
3. Random Forest
4. Gradient Boosting

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared (R2)

## Technologies Used

- Python
- Pandas
- Scikit-learn
- MLflow
- Streamlit
- FastAPI
- Feast

## Dashboard

The Streamlit dashboard displays model comparison results,
performance charts and the saved API prediction result.
